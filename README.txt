TJ LODGE | HOCKEY HUB — VERSION 1

OPEN: index.html in a browser for a local preview.

PUBLISH: Upload the entire contents of this folder to the same static web host used for your Nationals app, or another HTTPS static host. Keep the assets folder and all files together.

INSTALL: Once hosted over HTTPS, open the site on iPhone/iPad Safari > Share > Add to Home Screen.

UPDATES: Send ChatGPT the latest complete ZIP plus new results/photos, so it can produce a replacement ZIP. hockey-data.json is the human-readable master record; app.js currently embeds a matching copy for offline/local use. Both must be updated together.

DATA: Only supplied records are included; some match scores/dates are pending confirmation. Two summer Junior A goalie appearances are a partial season, not career totals.

PRIVACY: This is a static site with no login. If you publish it to a public host, the photos and information will be accessible to anyone with the URL (and possibly indexed). Consider password-protected hosting if privacy matters.

All gallery photographs are sourced from user uploads, resized without face alterations.
